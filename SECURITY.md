# Security policy

## Supported versions

Security fixes target the latest stable release. Give the exact version and, for a development build, the commit or Actions run. [Release list](https://github.com/soroushneyestani/developer-cli-toolkit/releases)

## Report a vulnerability

If private vulnerability reporting is available, open the repository's **Security** tab, choose **Advisories**, and select **Report a vulnerability**. Otherwise use an existing private channel with the maintainer. If you need a channel, ask only for private contact through an issue and keep the details out of the issue. [Security advisories](https://github.com/soroushneyestani/developer-cli-toolkit/security/advisories)

Include the affected version, OS, impact, and enough context to verify the behavior using an authorized synthetic workspace. Leave out credentials, private data, and production files. Coordinate any public disclosure with the maintainer so a fix and advisory can be prepared.
